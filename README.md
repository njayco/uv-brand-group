# Unrevealed Brand

**A Subsidiary of UV Music Group**

The Product Development Arm and Revenue Infrastructure Studio of UV Music Group. Licensed to Build Revenue.

## About

Unrevealed Brand is the technology and product development division of UV Music Group, dedicated to building revenue-generating digital products through the **100 Apps Project** — an initiative to create 100 applications spanning internal infrastructure tools and commercial builds for outside businesses.

## Features

- **Splash Screen** — Animated entry with UV Brand logo and loading bar
- **Home Page** — Hero section, Creative License card, Mission statement, Revenue Infrastructure overview, Support tiers, and Pricing
- **The 100 Apps Project** — Portfolio showcase of internal and commercial applications
- **Apply for a Project** — DMV-inspired application form for commercial development requests
- **Company Structure** — Interactive hierarchy diagram of UV Music Group
- **Contact** — Contact form with email notifications via Resend

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS, Framer Motion, Shadcn UI
- **Backend:** Express.js, Node.js
- **Routing:** Wouter
- **Forms:** React Hook Form + Zod validation
- **Data Fetching:** TanStack React Query
- **Email:** Resend (transactional email notifications)

## Design System

Inspired by official certificates and DMV Creative License documents with a New York State aesthetic:

- **Typography:** Playfair Display (headings), Inter (body), Libre Baskerville (serif body), Space Mono (monospace)
- **Color Palette:** Cream/tan paper backgrounds, navy primary, muted red accents
- **Patterns:** Guilloche line patterns, certificate borders, section dividers

## Getting Started

```bash
npm install
npm run dev
```

The application runs on port 5000.
